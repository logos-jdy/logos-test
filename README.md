# Todo List 📝

HTML, CSS, JavaScript로 만든 간단한 **할 일 관리 웹페이지**입니다.
GitHub의 파일 업로드, Commit, Branch, Pull Request 등 기본 기능을 실습하기 위한 예제 프로젝트입니다.

## 주요 기능

- **할 일 추가:** 입력창에 할 일을 적고 `Add` 버튼을 누릅니다.
- **Enter 키 지원:** 입력창에서 Enter 키를 눌러도 할 일이 추가됩니다.
- **완료 표시:** 추가된 할 일을 클릭하면 취소선이 표시되고, 다시 클릭하면 해제됩니다.
- **빈 입력 방지:** 내용을 입력하지 않고 추가하려고 하면 안내 메시지가 표시됩니다.

> 참고: 현재 버전은 브라우저 새로고침 시 등록한 할 일이 초기화됩니다. 서버나 데이터베이스, 로컬 저장 기능은 포함되어 있지 않습니다.

## 파일 구성

```text
Todo-List/
├── index.html   # 웹페이지 구조
├── style.css    # 화면 디자인
├── script.js    # 할 일 추가 및 완료 처리
└── README.md    # 프로젝트 설명서
```

## 실행 방법

1. 프로젝트의 네 파일을 같은 폴더에 둡니다.
2. `index.html` 파일을 더블클릭해 웹 브라우저에서 엽니다.
3. 입력창에 할 일을 입력한 다음 `Add` 버튼을 클릭합니다.
4. 목록에 추가된 할 일을 클릭해 완료 여부를 표시합니다.

별도 설치나 라이브러리 없이 실행할 수 있습니다. VS Code의 Live Server 확장 기능으로 열어도 됩니다.

## 사용 예시

1. 입력창에 `GitHub 매뉴얼 작성` 입력
2. `Add` 클릭 → 목록에 할 일 추가
3. 할 일을 클릭 → 완료 표시(취소선)
4. 같은 항목을 다시 클릭 → 완료 표시 해제

## GitHub 실습 예시

이 프로젝트로 다음 작업을 연습할 수 있습니다.

1. **Repository 생성:** GitHub에서 새 저장소를 만듭니다.
2. **파일 업로드:** `index.html`, `style.css`, `script.js`, `README.md`를 올립니다.
3. **Commit:** 파일을 수정하고 변경 내용을 기록합니다.
4. **Branch:** 별도 브랜치를 만들어 기능을 수정합니다.
5. **Pull Request:** 수정한 브랜치를 `main`에 병합하도록 요청합니다.
6. **Merge:** 변경 내용을 확인한 뒤 병합합니다.

### 추천 수정 과제

- `style.css`의 배경색 변경하기
- `script.js`에 새로운 기능 추가하기
